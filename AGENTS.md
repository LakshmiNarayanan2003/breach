# Working on BREACH

This repository uses Node.js 24, strict TypeScript, Three.js, Vite, Web Audio, Vitest and Playwright. Each cloud task already has an isolated environment: use this existing checkout; do not create a Git worktree unless explicitly requested.

Read README.md and the relevant docs before making behavior changes. Source of truth for gameplay is src/core/game.ts; keep it independent of browser and rendering APIs. Assets are original and bundled. Do not introduce external gameplay services, credentials, streaming audio, telemetry, or unlicensed assets.

Use npm ci. Validate with npm run typecheck, npm run lint, npm run test, npm run build and npm run test:e2e as appropriate. Browser tests use the production build at /breach/ and must run after a build. Use the installed /usr/bin/chromium or npx playwright install chromium when needed. Never present a simulated boundary-state test as a complete end-to-end playthrough.

Preserve source, lockfile, and user work during environment-only setup. Coding tasks may modify them as needed. Generated audio can be regenerated by scripts/generate_audio.py (NumPy required), but WAV files are already committed and normal development does not require regeneration. Keep licensing/provenance and tests current. Test critical audio with decoded signal output, not only mocks.

No sub-agent delegation is required. Do not publish or claim a live website without checking actual GitHub/Pages results.
